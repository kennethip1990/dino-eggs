英雄認字記錄（第一下就啱 / 次數）

字聽字揀卡睇字搵位

★ = 老師未剔，會出多啲。「睇字搵位」先係真正自己睇字，填工作紙「家長評估」可以參考呢欄。

Super Rex 英文記錄（第一下就啱 / 次數）

動物聽音撳圖睇字撳圖數腳

「睇字撳圖」= 自己睇英文字（工作紙 Look, read and match）；「數腳」= two legs / four legs。

生日派對認字記錄（第一下就啱 / 次數）

字開門認人坐位分類派嘢指令

★ = 老師未剔。「坐位分類」淨係睇字（冇圖、冇讀出嚟），先係真正自己認字；「派嘢指令」= 聽一步 / 兩步指令（升小面試考專注同聆聽）。

小記者錄音（淨係存喺呢部 tablet）

ABC 貪食蛇

下一局字母 　字款

每局跟次序食 5 個字母（U–Z 係 6 個），玩完自動去下一組。「大細楷配對」= 上面顯示大楷、要食細楷。

短片同貼紙簿

每個 game 3 個結局（英雄 5 個）：未睇過嘅先出（全部睇到），之後隨機。睇完新結局攞貼紙；主選單撳貼紙可以再睇。英雄 3 張 + Super Rex 3 張 → 主選單頂嘅秘密短片解鎖（貪食蛇 / 派對貼紙唔計）。
