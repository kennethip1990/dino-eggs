Jedi Luca 英文記錄（第一下就啱 / 次數）

字✓✗ 句子砌字Sith 決鬥

Mecha-Rex 英文記錄（第一下就啱 / 次數）

字聽方位睇方位砌字✓✗ 句子

方位字跟 Notes2（Part B）：「聽方位」= 聽句子揀圖，「睇方位」= 睇句子揀字（工作紙 Part B 就係咁考）。★ = 工作紙冇考到（under / in front of），第一下就啱 3 次之前每局都出；「兩個字」= next to 分開兩個字（工作紙寫咗 nextto）。砌字 = Part 3 VCe 字；✓✗ = Part 1（決鬥入面，有陷阱圖：直升機 ≠ plane 等）。

機甲 Luca 英文記錄（第一下就啱 / 次數）

字✓✗ 句子能量核心砌字ee / ea

「✓✗ 句子」= 工作紙 Part 1 Digraphs（有陷阱圖：山羊 ≠ sheep、老鼠 ≠ mouth、梳化 ≠ chair、T-shirt ≠ shirt、蛋糕 ≠ lunch）；「能量核心」= 聽字揀 sh / ch / th / ph；「砌字」= Part 3 Long ee / ea（多一粒干擾字母），★ = 工作紙嗰 4 個字；「ee / ea」= 決鬥入面揀 ee 定 ea。呢個 game 有 5 格護盾：答錯扣一格、讀多次題目先畀再答；冇晒就返基地叉電、重玩嗰一關；一格都冇扣 = 金勳章。

光之巨人英文記錄（第一下就啱 / 次數）

字✓✗ 句子光球砌字似 cow / bowl

跟 Yorkland Part 3 W-controlled（cow / new / bowl / prawn）+ R-controlled（horse / arm / bird / skirt）。「✓✗ 句子」有陷阱圖（杯 ≠ bowl、裙 ≠ skirt、腳 ≠ arm、蟹 ≠ prawn、舊梳化 ≠ new、綠色 ≠ brown）；「光球」= 聽字揀 ow / ew / aw 或 or / ar / ir；「砌字」★ = 工作紙 8 個字（第一下就啱 2 次之前排先），多一粒干擾字母；「似 cow / bowl」= ow 嘅兩個音（brown / owl 似 cow；snow / yellow 似 bowl）。冇扣血：第一下就啱先加一粒光，答錯要聽多次先畀再撳；一關光儲滿 = 金勳章，四關都金 = 金色貼紙。

恐龍時光機認字記錄（第一下就啱 / 次數）

詞聽字揀卡睇圖揀字砌詞

單元六：其他。★ = 老師未剔，第一下就啱 2 次之前會排先出。「睇圖揀字」唔會讀出個詞，先係真正自己睇字，填工作紙「家長評估」可以參考呢欄（生活 / 事情 / 地方 / 國家 太抽象冇圖）。干擾卡會用共用一粒字嘅詞：生日 / 生活、故事 / 事情、中國 / 國家。冇扣分：第一下就啱先加一粒化石，答錯要聽多次先畀再撳；一關化石儲滿 = 金勳章。

怪獸收集隊數學記錄（第一下就啱 / 次數）

數幾多粒球邊個係揀咗個位數

球盒 = 十格框（一盒十粒）。「幾多粒球」= 睇一盒 + 散球揀數字；「邊個係」= 聽數字揀啱嗰堆球。「揀咗個位數」= 例如 13 揀咗 3、或者揀咗冇盒嗰堆 → 未明白「一盒 = 十」。★ = 老師提嘅 10+1、10+2，第一下就啱 2 次之前排先。答錯唔扣：幾多粒球答錯會示範「呢盒係十，十一、十二……」先畀再揀。

怪獸果子店數學記錄（第一下就啱 / 次數）

數砌果十加幾第一下拎散果揀咗個位數

「砌果」= 客人要 N 粒，由貨架拎一盒（十）+ 散果；放多咗會放返一個落去（冇扣），「第一下就啱」= 冇放多咗。「第一下拎散果」= 開頭冇拎盒、由散果開始 → 可能仲係由一數起。「十加幾」= 10 + 3 = ? 揀數字，「揀咗個位數」= 揀咗 3。★ = 10+1、10+2、10+3 排先。圖鑑 / 拍檔同收集隊共用。
